During this internship, I worked on **end-to-end AI projects** involving data collection, preprocessing, feature extraction, model training, evaluation, and prediction.

Each project follows a structured pipeline similar to industry workflows.

---

## 🔹 Internship Tasks Completed

### ✅ TASK 2: Emotion Recognition from Speech

**Objective:**  
Recognize human emotions (e.g., happy, sad, angry, neutral) from speech audio.

**Approach:**  
- Audio signal processing using MFCC feature extraction  
- Deep Learning models using LSTM / CNN  
- Multiclass emotion classification

**Key Highlights:**
- MFCC (Mel-Frequency Cepstral Coefficients) feature extraction
- Sequence modeling using LSTM
- Model evaluation and prediction on unseen audio samples

**Dataset Used:**  
- RAVDESS (Ryerson Audio-Visual Database of Emotional Speech and Song)

---

### ✅ TASK 3: Handwritten Character Recognition

**Objective:**  
Identify handwritten digits and characters from images.

**Approach:**  
- Image preprocessing and normalization
- Convolutional Neural Networks (CNN)
- Multi-class classification

**Key Highlights:**
- Digit and character recognition
- CNN-based feature extraction
- Extendable to word or sentence recognition using CRNN

**Datasets Used:**  
- MNIST (Digits)  
- EMNIST (Characters)
